# Flow 3 — Олег шукає мешканця

Джерело: `flows.md › Flow 3`. Персона — Олег, роль «маю кімнату» / «обидва».
**Макета немає жодного екрана цього флоу** [опис]: поведінка — з `flows.md`,
текст — з історичного інвентарю `microcopy.md › Повний інвентар`. Перш ніж
будувати, потрібен дизайн екранів [дизайн-задача → Q26].

Спільні правила — [`common.md`](common.md), поля — [`validation.md`](validation.md).

## 1. Мої оголошення

| Стан | Коли | Посилання |
|---|---|---|
| Порожньо | оголошень ще немає → «Створити оголошення» | `microcopy.md › Повний інвентар › my-listings-empty.html` |
| Завантаження | — | `… › my-listings-loading.html` |
| Помилка | список не завантажено, оголошення не видалено | `… › my-listings-error.html` |
| Є активне | → стрічка людей-шукачів | `flows.md › Flow 3 › «Є вже активне оголошення?»` |

## 2. Опублікувати оголошення

**Кроки.** Форма → «Опублікувати оголошення» → «Мої оголошення» зі
статусом «Активне».

| Стан | Коли | Посилання |
|---|---|---|
| Порожній | нова форма | `… › listing-new-empty.html` |
| Помилка валідації | обовʼязкові поля порожні: зведення над формою + помилка під кожним полем; решта введеного збережена | `… › listing-new-error.html`; правила — [`validation.md` › Оголошення](validation.md) |
| Публікація | після submit; людина не закриває сторінку | `… › listing-new-loading.html` |
| Успіх | оголошення в «Моїх оголошеннях» і в стрічці | `… › listing-new-error.html › p` (останній: що буде після публікації) |

**Edge cases.** Тип оголошення — підселення чи оренда з нуля
(`CLAUDE.md › Ключові продуктові рішення › Модель контенту`). Модерація перед
показом у стрічці, редагування й закриття оголошення — [відкрито → Q27].

з фільтрами за районом і звичками.

| Стан | Посилання |
|---|---|
| Порожньо: звужено фільтром | `microcopy.md › Повний інвентар › seekers-empty.html` |

Як лістер приймає чи відхиляє вхідну заявку від шукача — тексту й опису
немає [відкрито → Q28].
