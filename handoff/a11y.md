# Доступність — що вже вбудовано і де

Це не план робіт. Це мапа доступності, яка **вже є** в дизайн-системі
`design-system/` і на 5 екранах активного прототипу («Стрічка кімнат»,
«Картка оголошення», «Анкета сумісності», «Заявка» — `lesson-6/`, і «Чати» —
`design-system/examples/chats.html`). Переносячи кіт у продукт, зберігай
кожен пункт: він уже працює й частково перевіряється автоматично.

**Як читати.** Кожен пункт — `- [x]` з трьома частинами:

- **Гарантія** — що саме виконано, одним реченням.
- **Де** — файл і селектор / токен / функція (`файл:рядок` станом на
  2026-10-08). Значення не переписані сюди — дивись у файлі.
- **Перевірка** — руками в браузері (що зробити, що має бути видно) і
  автоматично (скрипт, гейт, команда; спільний запуск — у кінці).

Шляхи — від кореня репозиторію. Темна тема `[data-theme="dark"]` — це
stress-test токенів, не прийняте продуктове рішення (`CLAUDE.md`, відкриті
питання), але кожен пункт нижче в ній працює. Перемкнути тему руками —
кнопка «Темна тема» в курсовій панелі або в консолі
`document.documentElement.dataset.theme = "dark"`.

Знайдені при зведенні прогалини позначено **Б1–Б8** і записано в
[`onboarding-gaps.md` → «Борг доступності»](onboarding-gaps.md#борг-доступності-виявлено-при-зведенні-a11ymd-2026-10-08).

## 1. Видимий фокус (`:focus-visible`) в обох темах

- [x] **Кільце фокусу на кожному фокусованому елементі.**
  - Гарантія: будь-який елемент, що отримав фокус з клавіатури, має суцільне

    колір — `--color-focus` у `design-system/tokens.css:286` (світла) і

    кільце світло-зелене. Клік мишею кільця не показує (це і є `:focus-visible`).
  - Автоматично: гейт `browser` у `scripts/qa-lesson-8.mjs:284–289` —
    сторінка мусить містити правило `:focus-visible` (лише наявність, див. **Б4**).

  - Перевірка руками: `lesson-6/listings.html` у рамці «Десктоп», відкрий

  - Де: правило — `DESIGN.md`, «Анімація» → «Технічні правила» («Кільце

## 3. Брейкпоінти в rem і container queries

- [x] **Межі розкладки йдуть за розміром шрифту користувача.**
  - Гарантія: обидві точки зміни поведінки задано в rem, тож людина зі

  - Де: токени `--bp-tablet` і `--bp-desktop` — `design-system/tokens.css:183–184`,

- [x] **Пороги — container queries від реального контейнера, з літералом,

    `kit-list`, `kit-page-intro`, `kit-detail`), а не вікна; кожен поріг у

## 4. `prefers-reduced-motion`

- [x] **Глобальний запобіжник: у режимі зменшеного руху кожна зміна
  стану миттєва.**
  - Гарантія: для всіх елементів і псевдоелементів анімації й переходи
    тривають `--dur-reduced` (0.01 мс), грають не більше разу, скрол без
    згладжування; кінцеві стани й події `animationend`/`transitionend`
    зберігаються.
  - Де: `design-system/components/base.css:36–43` (пояснення `:20–35`);
    токен `--dur-reduced` — `tokens.css:492–496`; правило — `DESIGN.md`,
    «Анімація» → «Технічні правила».
  - Перевірка руками: DevTools → ⋮ → More tools → Rendering → «Emulate CSS
    media feature prefers-reduced-motion» → `reduce`; навести й натиснути
    кнопку на `design-system/docs/button.html` — колір змінюється одразу,
    кнопка не стискається.

- [x] **Токени руху самі обнуляються.**
  - Де: `@media (prefers-reduced-motion: reduce)` у `tokens.css:534–541` —
    `--move-sm`, `--move-md` = 0, `--press-scale`, `--press-scale-sm` = 1
    (оголошення — `:504–512`).

- [x] **Кожен файл кіта з рухом має власний `@media (prefers-reduced-motion)`;
  WAAPI-рух не запускається.**
  - Де: `button.css:49–51` (коло hover не росте, кнопка не стискається);
    `split-view.css:127–133` (пульс завантаження вимкнено);
    `split-view.js:181–186` — `reducedMotion()` через `matchMedia`, FLIP-перехід
    `.animate()` не стартує.
  - Статус процесу — текстом, не рухом: `.kit-split__status` з
    `role="status"` і `aria-live="polite"` (`split-view.js:90–99`,
    `split-view.css:139`), поки деталь має `aria-busy="true"`.

- [x] **Автоматичні перевірки руху.**
  - Гейт `motion` — `scripts/qa-lesson-8.mjs:74–174`: тривалості лише
    `var(--dur-*)`, криві `var(--ease-*)`, `@keyframes` лише
    `transform`/`opacity`, кожен файл з рухом має `prefers-reduced-motion`,
    наявність глобального блоку в `base.css` (`:140–154`), заборона плавного
    скролу і `.animate()` без `matchMedia` у JS.
  - `scripts/qa-reduced-motion.mjs` — емулює `reduce` через CDP на 5 екранах
    і docs кнопки та split-view: обчислені тривалості ≤ 0.01 мс, без
    масштабу в pressed/hover, видимий «Завантажуємо…» поки `aria-busy`,
    деталь не зсувається.
  - Документація каже, що компоненти рух ще не споживають, — це не так
    (**Б8**, пункт 14 у `onboarding-gaps.md`).
