# Спільні правила станів

Діють у кожному флоу, якщо файл флоу не каже інакше. Позначки — див.
[`README.md`](README.md).

## Помилка валідації поля

- **Коли зʼявляється.** Лише після дії людини: натискання головної кнопки
  кроку чи форми («Зберегти й далі», submit). Під час набору помилки не
  показуємо. [прототип: `compatibility-form.html`, функція `stepIsValid`;
  `application.html`, обробник `submit`]
- **Що відбувається.** Дія не виконується, фокус переходить на перше
  невалідне поле. Інші поля не очищаються.
- **Як виглядає.** Поле у стані помилки — компонент `form`, стан error
  (`kit-field--error` + `.kit-field__message`) →
  [`docs/form.html#states`](../design-system/docs/form.html#states).
  Повідомлення — під полем, у `.kit-field__message`, і назване через
  `aria-describedby`. Колір не єдиний сигнал — `DESIGN.md › The Evidence Has
  Words Rule`.
- **[трюк прототипу]** Прототип показує нативну підказку браузера
  (`reportValidity`). У продукті — стан error компонента `form`.
- **Текст.** Шаблон — `voice.md › Додаткові контракти › Валідація` (поле,
  умова, виправлення). Конкретні тексти — у [`validation.md`](validation.md).
- **Коли зникає.** [відкрито → Q1]

## Відправка даних (завантаження після дії)

- Головна кнопка — компонент `button`, стан disabled
  ([`docs/button.html#states`](../design-system/docs/button.html#states)) на
  весь час запиту; підпис називає процес. Повторне натискання неможливе.
  Джерело правила: `microcopy.md › Рішення аудиту`, рядок «Loading-кнопка не
  називала процес»; приклад — `microcopy.md › Повний інвентар ›
  chat-loading.html › p`.
- Статус процесу — текстом у `role="status"`, не лише рухом
  (`DESIGN.md › Анімація`, абзац про `prefers-reduced-motion`).
- Поля на час запиту не змінюються. Якщо відправка незворотна, текст
  попереджає не закривати сторінку (приклад —
  `microcopy.md › Повний інвентар › profile-edit-loading.html › p`).
- Текст завантаження: що відбувається, без обіцянки часу —
  `voice.md › Правила за типом елемента › Завантаження`.

## Збій мережі або сервера

- **Введене не губиться.** Після збою форма показує все, що людина ввела. Це
  наскрізне правило історичного копі: «Текст заявки зберігся», «Твої фільтри
  збереглися», «Твій вибір лишився у формі» (`microcopy.md › Повний інвентар`,
  файли `*-error.html`).
- **Структура тексту:** факт → причина, якщо відома → одна дія
  (`voice.md › Правила за типом елемента › Помилка`). Дія повтору — «Спробувати
  ще раз» (`microcopy.md › Рішення аудиту`, перший рядок).
- **Компонента для помилки рівня форми чи екрана в кіті немає:**
  `kit-note--error` і `kit-state--error` прибрано під час прунінгу
  (`design-system/backlog.md › Прибрано`). [дизайн-задача → Q2]

## Завантаження екрана чи списку

- Єдиний реалізований стан завантаження — деталь оголошення у split-view на
  десктопі: `split-view.js`, шапка, абзац «Завантаження»; компонент
  [`docs/split-view.html#states`](../design-system/docs/split-view.html#states).
- Для решти екранів стану завантаження немає: skeleton прибрано з кіта
  (`design-system/backlog.md`, «Модулі (17 → 16)»). [дизайн-задача → Q3]
- Якщо завантаження деталі у split-view не вдалося — переходимо на повну
  сторінку оголошення (`split-view.js`, `options.fallback`).

## Порожній стан

- Текст: чому порожньо → що змінити або створити
  (`voice.md › Правила за типом елемента › Порожній стан`).
- Компонент — `kit-state` у картці (`components/card.css`, коментар
  «Стан (kit-state)»; [`docs/card.html#states`](../design-system/docs/card.html#states)).
- Розрізняти два порожні стани: **«звужено фільтром»** (є вихід — змінити
  фільтри) і **«справді нічого немає»** (глухий кут, виходу в продукті поки
  немає). Див. `flows.md › Flow 1 › «Фільтри вже максимально широкі?»`.

## Успіх

- Текст: що змінилося → природний наступний крок, без «успішно»
  (`voice.md › Правила за типом елемента › Підтвердження`).
- Фокус переходить на заголовок результату (зразок — `application.html`,
  `#prototype-result` з `tabindex="-1"`).

## Доступ, якого в ролі немає

Пункт, недоступний поточній ролі чи ще не збудований, показується вимкненим
з поясненням, а не ховається: `aria-disabled="true"` + підказка поруч
(зразок — сегмент «Люди» в `listings.html`, `#people-feed-hint`). Яку
навігацію бачить кожна роль — `CLAUDE.md › Інформаційна архітектура ›
Навігаційна модель`.
