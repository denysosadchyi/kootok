# Інвентар мікрокопі

> **Історичний документ (Beginners / урок 6 до перебудови 2026-09-17).** Не є чинним: канон — `/CLAUDE.md`, `/DESIGN.md`, `/design-system/`, `/concept.md`. Збережено як історію.

Початкове джерело: історичний набір HTML-екранів. Чинне джерело для
активного сценарію — чотири файли у `prototype/`: Пошук, Оголошення,
Сумісність і Заявка. Архівні редакції нижче не перевизначають copy живого
прототипу. Позначки в самому рядку:

- **[Користувач — не редагувати]** — контент, який створює користувач або автор оголошення.
- **[Неузгоджено: …]** — різні формулювання того самого предмета / дії.
- **[Заглушка]** — тимчасовий текст макета.
