# Куток

Пошук співмешканців і вільних кімнат у Києві. Mobile-first веб.

Головна цінність — **довіра**: зняти тертя й ризик у момент, коли людина
шукає, кого підселити, або куди заїхати.

**Сайт проєкту:** https://kkutok.vercel.app

Наскрізний кейс курсу «Design Engineering Beginners». Репозиторій — це
робочі матеріали продукту: бриф, конкурентне дослідження, дизайн-висновки
і генератор сайту, на якому все це читається.

## Продукт коротко

| | |
|---|---|
| Аудиторія | 22–30 років, переїзд у Київ або вже живуть там |
| Сценарії | підселення до співмешканців · пошук співмешканця з нуля · оренда напряму від власника |
| Географія й мова | тільки Київ, українська |
| Контент | тільки від користувачів, без агрегації з OLX/FB |
| Комунікація | внутрішній чат, номер телефону приховано |
| Монетизація | відсутня на старті — фокус на зростанні бази |
| Етап | design-first: проєктуються 4 ключові екрани, tech stack не обраний |

**Відкриті питання:** механізм верифікації, команда й терміни, метрика
успіху MVP. Повний бриф — [CLAUDE.md](./CLAUDE.md).

## Що вже зроблено

Уроки 1–2 курсу.

- **[CLAUDE.md](./CLAUDE.md)** — продуктовий бриф: три сценарії матчингу,
  ключові рішення, відкриті питання, пріоритетні екрани, список
  конкурентів з обґрунтуванням.
- **[research/research.md](./research/research.md)** — дослідження ринку:
  15 конкурентів у трьох групах (хард / софт / аспіраційні), порівняння
  за 5 осями, 3 спільні патерни ринку, прогалини, **5 гіпотез** до
  перевірки, питання до PM.
- **[research/screens](./research/screens)** — 44 скріншоти ключових
  екранів конкурентів, зняті через Playwright у мобільному viewport.
  Недоступні без входу екрани підписані «доступ обмежений» — вміст за
  ними не реконструювався.
- **[research/notes/trust-dimension.md](./research/notes/trust-dimension.md)**
  — вимір довіри до профілю: Airbnb, BlaBlaCar, Bumble, Upwork, Turo за
  8 критеріями, і що з цього переносимо в MVP.
- **[research/notes/ux-patterns.md](./research/notes/ux-patterns.md)** —
  п'ять механік пошуку співмешканця: коли працюють і коли ламаються.
- **[research/design-implications.md](./research/design-implications.md)**
  — що дослідження означає для чотирьох пріоритетних екранів, і драбина
  сигналів довіри від нульових до платних.

**Ключові знахідки:** довіра ніде не тримається на одному бейджі —
завжди стек сигналів; там, де немає внутрішнього чату, люди самі
публікують телефон у відкритому тексті; сумісність ніде не є головною
віссю пошуку.

## Сайт проєкту

Статичний сайт із навігацією за уроками курсу, генерується з тих самих
markdown-файлів.

```bash
pip install markdown
python3 _build/build.py          # збирає _site/
python3 -m http.server 8200 -d _site
```

Деплой на Vercel автоматичний: пуш у `main` → збірка (`_build/build.py`)
→ публікація `_site`. Зібрані сторінки в репозиторії не зберігаються.

Дизайн-система сайту — [SITE-DESIGN.md](./SITE-DESIGN.md), продуктовий контекст —
[PRODUCT.md](./PRODUCT.md).

