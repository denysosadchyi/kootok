# SITE-DESIGN.md — сайт проєкту Куток

Дизайн-система внутрішнього сайту-артефакту (`_site/`, генерується
`_build/build.py`) — тобто оформлення матеріалів проєкту, **не** дизайн
самого продукту Куток. Продуктові токени — у `figma-tokens.md`.
Register: **product**.

## Напрям

Мова креслення. Куток — про кімнати, метри й пороги; сайт узятий із
світу архітектурного плану: тонкі виміряні лінії, аркуші з номерами,
технічна анотація на полях, щільна таблична подача. Не «редакційний
журнал», не «SaaS-документація».

Чому не інакше: обидва очевидні рефлекси відкинуто свідомо — біло-синя
docs-стандартність (перший рефлекс категорії) і тепла кремова
editorial-естетика з serif+теракотою (другий рефлекс, уже використаний
у ранньому артефакті цього ж проєкту).

## Тема

Тільки світла. Сценарій: людина читає дослідження вдень з ноутбука,
паралельно працюючи в іншому вікні. Креслення живе на папері, не в
темряві.

## Колір

Стратегія: **Restrained** — тоновані нейтралі + один акцент ≤10%
поверхні. Колір несе стан, не прикрашає.

| Роль | OKLCH | Призначення |
|---|---|---|
| `--paper` | `oklch(0.988 0.003 95)` | основна поверхня контенту |
| `--panel` | `oklch(0.962 0.005 250)` | ліва панель, шапки таблиць (холодніша за папір) |
| `--ink` | `oklch(0.245 0.014 265)` | основний текст |
| `--ink-2` | `oklch(0.46 0.012 265)` | вторинний текст |
| `--ink-3` | `oklch(0.62 0.010 265)` | підписи, метадані |
| `--rule` | `oklch(0.90 0.006 265)` | лінії, межі |
| `--rule-firm` | `oklch(0.80 0.008 265)` | акцентовані лінії |
| `--accent` | `oklch(0.505 0.165 32)` | поточний розділ, посилання, маркер |
| `--accent-wash` | `oklch(0.955 0.022 40)` | підкладка активного пункту |
| `--open` | `oklch(0.55 0.115 75)` | семантика «відкрите питання» |
| `--open-wash` | `oklch(0.965 0.030 85)` | підкладка блоку відкритого питання |

Акцент — колір редлайну на кресленні (правка, анотація). Він же маркує
поточний аркуш у навігації. Бурштиновий `--open` — окрема семантика для
невирішених питань, не декор.

Ані `#fff`, ані `#000`: усі нейтралі тоновані в бік `265°`.

## Типографіка

Одна сімʼя для інтерфейсу й тексту + моноширинна для анотацій.

- **Текст/UI:** `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`
- **Анотації:** `ui-monospace, "SFMono-Regular", Consolas, monospace` —
  номери аркушів, дати, шляхи до файлів, шапки таблиць
- Шкала фіксована в `rem`, крок ≈1.2: `0.72 / 0.8 / 0.875 / 1 / 1.125 /
  1.35 / 1.7 / 2.05`
- Проза — 68ch. Таблиці щільніші, зі своїм прокручуванням.
- Заголовки: `text-wrap: balance`, вага 600–650, без display-шрифтів.

## Структура

Двоколонковий каркас: фіксована ліва панель (аркуші проєкту за
фазами, з номерами й статусом) + права колонка контенту. На вузькому
екрані панель згортається в шапку з перемикачем.

Довгі документи отримують внутрішній перелік розділів угорі — вхід у
потрібне місце за один крок.

## Компоненти

- **Аркуш у навігації:** номер (моно) + назва + крапка статусу. Стани:
  default / hover / focus-visible / current.
- **Таблиця:** шапка на `--panel`, моношрифт, `overflow-x: auto` у
  власному контейнері; рядки розділені `--rule`.
- **Блок відкритого питання:** підкладка `--open-wash`, повна межа,
  без бічної смуги.
- **Скріншот:** повна межа, підпис моношрифтом; недоступні екрани
  позначені текстом «доступ обмежений», не кольором.

## Заборонено

Спільні заборони impeccable плюс локальні:

- бічні кольорові смуги (`border-left` як акцент)
- градієнтний текст, glassmorphism
- однакові сітки карток «іконка + заголовок + текст»
- декоративна анімація; переходи лише 150–200 ms на стан
- serif-заголовки й кремовий фон (використані в ранньому артефакті)
