# Логотип «Куток»

## Ідея

Знак поєднує простий силует дому зі «спільною лавою» — горизонталлю всередині. Дві опори формують окремі куточки, а проміжок між ними лишається відкритим: це метафора власного простору всередині спільного дому й двору. Геометрія навмисно проста, без дрібних деталей, тому знак зберігає силует у розмірі 16–30 px.

## Файли й використання

- `mark.svg` — знак у `viewBox="0 0 24 24"`, без тексту і без вшитого кольору. Усі штрихи використовують `currentColor`.
- `lockup.svg` — горизонтальний знак зі словом «Куток». Літери побудовані контурами, тому SVG не залежить від завантаження шрифту; увесь lockup також успадковує `currentColor`.
- Рекомендований колір у продукті — глибокий зелений `#245744`. На темному тлі можна задати білий через CSS `color`.

Знак не використовує лайм: за дизайн-контрактом лайм позначає лише поточний або вибраний стан, а бренд-марка лишається лісово-зеленою.
