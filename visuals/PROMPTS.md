# Структура промптів

Зображення створено вбудованим генератором зображень, окремим викликом для кожного asset. Для всіх викликів використано `Use case: photorealistic-natural`.

## Спільна основа кімнат

- призначення: фото картки оголошення «Кутка»;
- фотореалістична документальна інтер’єрна зйомка, 3:2, рівень очей, умовний об’єктив 28 мм;
- природне київське житло відповідної епохи: панельний, цегляний довоєнний або новий будинок;
- тепле денне світло, лляні нейтральні, натуральне дерево, стримані зелені деталі;
- звичайні меблі, природний знос, охайно, але житлово;
- окремий опис району, типу квартири, мешканців, ціни й деталей кімнати для кожного файла;
- обмеження: без людей, тексту, логотипів, водяних знаків, HDR, люксового стейджингу, fisheye і неможливої геометрії.

## Спільна основа аватарів

- призначення: квадратний портрет профілю «Кутка»;
- вигаданий українець або українка 18–30 років, окремі зовнішність, одяг і характер для кожного імені;
- кадр по плечі, рівень очей, умовний об’єктив 50 мм, безпечне центрування для круглого crop;
- природне тепле світло з вікна, фон київської квартири або зеленого двору;
- реальна текстура шкіри, природне волосся, повсякденна тканина, єдиний теплий лляно-зелений color grade;
- обмеження: не знаменитість, без тексту, логотипів, водяних знаків, beauty filter, ретушного або студійного блиску.

Варіативна частина кожного промпту зафіксувала ім’я, вік/роль, район або оголошення, зовнішні ознаки й одяг. Це дало окреме обличчя кожному персонажу та окремий інтер’єр кожному оголошенню.
