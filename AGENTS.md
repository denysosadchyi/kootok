# Agent workflow

- Усі файлові правки в цьому проєкті виконує призначений агент. Кореневий агент лише координує роботу та перевіряє результат.
- Нові користувацькі правки спочатку додаються до `IMPLEMENTATION_PLAN.md`; після делегування кореневий агент очікує статуси призначених агентів перед фінальним висновком.
