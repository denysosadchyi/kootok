Куток · Design System

Галерея

Горизонтальна добірка реальних фото з видимим наступним кадром.

Анатомія

  1. Семантичний список кадрів.
  2. Змістовний alt описує відмінність фото.
  3. Scroll snap підтримує навігацію по горизонталі.

Варіанти й розміри

Світла тема

Default · 280 × 210 (4:3)

Темна тема

Default · 280 × 210 (4:3)

Єдиний варіант — default на сторінці оголошення. Якщо фото більше одного, наступний кадр видно з краю.

Коли вживати

Галерея допомагає оцінити реальний простір до заявки. Вона є головною емоційною точкою деталі, але не замінює ціну, район і побутові факти.

Правило й антиправило

Правило

Кілька різних фото кімнати показуй у gallery з точними alt.

Антиправило

Не використовуй gallery для одного аватара; обери avatar або person.
