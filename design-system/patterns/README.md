# Патерни дизайн-системи «Кутка»

Патерн — стабільна композиція чинних компонентів, яка розв'язує ту саму
продуктову задачу з тією самою семантикою. Компонент — окремий елемент із
власними варіантами й станами (`components/`), патерн — лише порядок і правила
поєднання компонентів.

## Поріг

Композицію оформлюємо як патерн, коли вона повторюється **щонайменше на 3
сторінках або в 3 екземплярах одного сценарію** з однаковою семантикою
(однакова задача, порядок компонентів і поведінка). Випадкова візуальна
схожість патерном не є. Жива сторінка каталогу — [`docs/patterns.html`](../docs/patterns.html).

## Як додати патерн

1. Переконайся, що всі частини вже є компонентами в `components/` і мають
   сторінки в `docs/` зі станами в обох темах.
2. Створи тут файл `<назва>.md`: задача, склад (класи), розмітка, правила,
   де вживається.
3. Додай картку патерна в `docs/patterns.html` (розділ «Прийняті патерни»).
4. Лише після цього застосовуй композицію на екранах.
